An ultra-modern, premium navigation bar featuring an advanced **Aslzoda's (Aqua) effect**. Inspired by Apple's high-end organic design language, this navbar blends premium glossy aesthetics with highly responsive micro-interactions.

✨ **[Live Demo on Netlify](https://aslzoda-anim.netlify.app)** 

---

## 🚀 Key Features

*   **💧 True Liquid Glass Effect:** Uses layered `backdrop-filter`, precise color saturation, and a unique glossy top-edge reflection curve to simulate authentic physical glass.
*   **💡 Dynamic Interactive Glare:** A hardware-accelerated 3D light cone follows the cursor movement across the navbar container in real-time.
*   **🌗 Adaptive Light/Dark Mode:** Completely independent, hand-crafted design palettes tailored for both themes with organic transitions.
*   **🎯 Apple Bouncy Animation:** The active background pill slides smoothly beneath items using custom spring physics (`cubic-bezier(0.34, 1.2, 0.64, 1)`).
*   **📱 Tactile Feedback:** Buttons realistically shrink slightly (`scale(0.92)`) upon click/tap, mimicking a physical click mechanism.
*   **🔮 Ambient Mesh Background:** Smoothly drifting fluid gradient blobs in the background provide rich colors for the glass interface to refract beautifully.

---

## 🛠️ Tech Stack & Architecture

*   **Semantic HTML5:** Built using clean, SEO-friendly, and accessible markup (`<nav>`, `<button>`, optimized inline SVGs).
*   **Modern CSS3:** Leveraging native CSS Custom Variables (`:root`) for instant, seamless theme toggling and hardware-accelerated animations (`will-change`).
*   **Vanilla JavaScript:** Zero-dependency, lightweight scripting optimized for tracking mouse coordinates and handling slider states efficiently.
